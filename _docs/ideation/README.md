# Ideation Approach
- Establish frameworks for grounding thinking
- Conceptually/theoretically tackle multiple problem statements
  - Allows exploration
  - Enables you to test frameworks
  - Prevents over-investment in any particular problem statement
- Pick the statement(s) that most match our requirements
